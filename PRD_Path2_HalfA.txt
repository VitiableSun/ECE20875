3. QUESTION 1: SENSOR PLACEMENT
--------------------------------------------------------------------------------

Goal:
  Determine which 3 of the 4 bridges to install sensors on so that Total bike
  traffic can be estimated as accurately as possible. Equivalently: find which
  single bridge is the least informative and can be left out.

Method -- Linear Regression (feature subset evaluation):
  - Treat the 3 bridge counts as input features (X) and Total as the target (y).
  - Try all 4 possible three-bridge subsets:
      Subset 1: Manhattan, Williamsburg, Queensboro (drop Brooklyn)
      Subset 2: Brooklyn, Williamsburg, Queensboro  (drop Manhattan)
      Subset 3: Brooklyn, Manhattan, Queensboro     (drop Williamsburg)
      Subset 4: Brooklyn, Manhattan, Williamsburg   (drop Queensboro)
  - For each subset, fit a LinearRegression model and evaluate performance.

Train/test split:
  - Use an 80/20 train/test split (random_state=42 for reproducibility).
  - Fit the model on training data, evaluate on test data.

Evaluation metric:
  - Report R^2 (coefficient of determination) for each subset on the test set.
  - Optionally also report MSE or RMSE.
  - The subset with the highest test R^2 is the recommended 3-bridge set.

Expected deliverable from code:
  - Print the R^2 (and optionally MSE) for all 4 subsets.
  - Print a clear recommendation: "Install sensors on: [Bridge A], [Bridge B],
    [Bridge C]. Drop: [Bridge D]."
  - Optional: a bar chart comparing R^2 across the 4 subsets.

Report content for Q1 (write these sections):
  Methods paragraph:
    - State that you used linear regression with 3-bridge subsets.
    - Justify why: linear regression is appropriate because Total is a
      continuous variable and is likely a near-linear sum of the individual
      bridge counts. Feature subset comparison via R^2 is a principled way
      to identify the least informative bridge.
    - State your expectation: the bridge with the lowest individual traffic
      (or the highest correlation with others) is most likely to be dropped.
  Results paragraph:
    - Report the R^2 for each subset.
    - State which 3 bridges you recommend.
    - Discuss why the dropped bridge was least informative (e.g., is its
      traffic volume lower? Is it highly correlated with another bridge?).

Goal:

  Precipitation) can be used to predict total daily bike traffic (Total).

Method -- Linear Regression:
  - Features (X): High Temp, Low Temp, Precipitation
  - Target (y): Total
  - Fit a LinearRegression model and evaluate predictive performance.

Train/test split:
  - Use an 80/20 train/test split (random_state=42 for reproducibility).
  - Fit on training data, evaluate on test data.

Evaluation:
  - Report R^2 and MSE/RMSE on the test set.
  - Print the regression coefficients for each feature (High Temp, Low Temp,
    Precipitation) to understand direction and magnitude of effect.

Visualization (required):
  - Scatter plot: predicted Total (x-axis) vs. actual Total (y-axis).
  - Include a y=x reference line so it is easy to see how well predictions
    track reality.

Expected deliverable from code:
  - Print coefficients, intercept, R^2, and MSE on test set.
  - Display the predicted vs. actual scatter plot.

Report content for Q2 (write these sections):
  Methods paragraph:
    - State that you used linear regression with weather variables as features.
    - Justify why: Total is continuous and weather is a plausible predictor of

    - State what you expect: higher temps likely increase ridership; more
